# Moquil on the web

Moquil is the MP social app (communities, chats, friends, profiles, store and library), here in a desktop-style window for the browser.

Open it: https://mpsamp-open.github.io/moquils-web/

- Log in or sign up with the same account as the Android app. The session is remembered, so you stay logged in next time.
- Android app and game: https://mpsamp-open.github.io
